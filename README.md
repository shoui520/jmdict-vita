# JMdict Vita

Japanese to English dictionary app for the PS Vita. Using ScePaf for the native Sony look and feel.

This is a sysapp that can run without closing out Vita applications or PspEmu applications. (-d ATTRIBUTE2=12 365MB extended memory applications require all sysapps to be closed).
